### 🚀 Featured Projects

#### ⚖️ [VeriLaw-AI](https://github.com/Sanjayazhagan/VeriLaw-AI)
**An AI-powered legal assistant designed to streamline contract analysis and legal research, built for high performance and enterprise-grade privacy.**

This project represents a complete, scalable alternative to Harvey AI, engineered with a focus on data security and horizontal scaling. 

**System Architecture (VeriLaw):**
1.  **Frontend:** React Review Dashboards provide a streamlined legal interface.
2.  **Privacy Layer:** Express.js API contains a mandatory **Privacy Scrubber** that redacts PII before any query is processed.
3.  **Parallel Scaling:** A Redis-based message queue manages asynchronous task distribution across multiple backend nodes.
4.  **AI Backend:** Multiple FastAPI RLM nodes synchronize with a shared Database. Each node uses an RLM agent to direct a pool of high-performance worker LLMs in parallel, ensuring massive throughput.

* **Tech:** Python, FastAPI, Express.js, React, Redis, LangChain, state-of-the-art LLMs, and advanced RAG.
* **Impact:** Developed a complete, privacy-preserving legal AI RAG alternative, demonstrating intricate distributed systems engineering and a focus on enterprise security.

#### 📚 [Study Sphere](https://github.com/Sanjayazhagan/study-sphere)
**A decentralized, pool-based notes sharing and RAG platform featuring a token economy for peer learning.**
* **Tech:** Node.js, Express, PostgreSQL, Pinecone, LangChain, Gemini 1.5
* **Impact:** Solved the "freeloader" problem in collaborative study environments by engineering an AI auto-grading pipeline. High-quality document uploads are rewarded with tokens, which are then consumed for highly accurate, hallucination-free AI queries within isolated vector namespaces.
